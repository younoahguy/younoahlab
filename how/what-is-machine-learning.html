What is machine learning?

Machine learning is when a computer works out a pattern from lots of examples, instead of being told every rule by a person.

How it works

  1. People collect many examples, such as thousands of pictures labeled cat or dog.
  2. The computer makes a guess for each example and checks whether it was right.
  3. Every wrong guess nudges some numbers inside the program so the next guess is a bit better.
  4. After a huge number of nudges it gets good at the pattern. If the examples were poor or unfair, what it learns will be too.

How do we know?

You can watch it happen in the AI & Agents lab, where a tiny program learns to sort fruit and you can see its numbers change. Frank Rosenblatt built the first machine of this kind, the perceptron, in 1958.
